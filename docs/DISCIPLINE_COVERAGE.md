# Choose contributions by the work

01 remains the single chat entrypoint. It selects useful methods, current native tools and recorded runtimes, then revises the combination as inputs, goals or failures change. Categories help navigation; they are not fixed pipelines or proof of readiness. Read selected full methods and their current prerequisites. A method, a source package and an accepted runtime operation are different things.

The five additions below are authored native methods grounded in recorded primary sources, not official extracted solver plugins. They add about 198 KB including retained source documentation and licenses. They install no solver, decoder, cloud service, model or device connection.

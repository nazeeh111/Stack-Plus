# Decoder contracts and primary sources

This is authored guidance. No Stim/PyMatching SDK, source implementation, dependency or runtime is bundled or installed. Those upstream projects retain Apache-2.0 licenses; nstack's authored method is MIT. SOURCE.json records exact source revisions and reference-file hashes. Recheck the actual selected tool/version before applying examples.

- [Stim detector error model format](https://github.com/quantumlib/Stim/blob/ffe0d043598ed5df0851a3e6b4920359a23fafbd/doc/file_format_dem_detector_error_model.md) defines detector symptoms, logical frame changes, error probabilities, relative detector indices and repetition blocks. A model's detector count and observable ordering belong to its contract.
- [Stim gate/annotation reference](https://github.com/quantumlib/Stim/blob/ffe0d043598ed5df0851a3e6b4920359a23fafbd/doc/gates.md) defines DETECTOR and OBSERVABLE_INCLUDE. Detector parities are referenced to deterministic noiseless behavior; they are not arbitrary groupings of measurement bits.
- [PyMatching documentation and examples](https://github.com/oscarhiggott/PyMatching/blob/6f63b2b9474ba0fa7e511fe52bffdce858a06984/README.md) state graphlike independent-error assumptions, boundary edges, correlated matching, and the Stim detector-sample/logical-observable comparison. An error incident on a boundary can cause one detection event. Decomposition is a modeling choice; do not silently treat correlated edges as independent physical faults.

For the small repetition lane, Z0Z1 and Z1Z2 are the checks. Under X errors, their negative outcomes correspond to bits (e0 XOR e1,e1 XOR e2). A lone Z error commutes with both checks, so its syndrome is 00 while it can flip the logical phase. A pair of X errors has the syndrome of the complementary single error: the lookup can leave a logical X. These controls expose what the code does not protect.

The companion Cirq method owns simulator APIs and explicit qubit/measurement order. The tested local lane used Cirq 1.7.0, ideal parity ancillas, mid-circuit ancilla measurement, correction chosen solely from measured syndrome, inverse decoding and reduced logical-state fidelity. A separate finite-shot density-matrix study measured joint data/parity bits and compared the decoded logical Z failure with an independent majority oracle. It used independent X noise once after encoding, not noisy repeated checks.

For independent data X probability p and ideal three-bit majority decoding, P(logical X failure)=3p²(1−p)+p³. This is a property of this noise/code/readout model, not a universal physical threshold. Repeated syndrome rounds with measurement errors require a spacetime detector model and temporal boundaries; they were not exercised by the small acceptance fixture.

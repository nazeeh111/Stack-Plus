# Native operation

Apply Hallmark to the selected interface task. Current user and host instructions, visual references and an approved project design take priority over its example themes and default design rules. Ask only for material missing decisions; existing answers and permission still count.

Read actual host capabilities. Codex here has browser tools and native workers; the upstream harness table is an older snapshot. A fresh review must use an actual fresh conversation when available, and otherwise be labelled an in-thread review. Do not change models, effort or permissions to match a recipe.

Use the installed Node scripts on explicit project files. Static checks need no package installation. For rendering, discover an existing compatible Puppeteer/Puppeteer Core module root and Chrome/Chromium executable. The bundled scripts accept HALLMARK_PUPPETEER and CHROME_PATH as per-command settings; they also check the project and supported browser locations. Use a fresh browser context and explicit target. Do not treat an absent browser/module as a rendered pass or install it automatically. Run in the project so generated .hallmark files stay there. Report static and rendered results separately.

Do not run install.mjs, install-hook.mjs, global npm installs or retired Claude configuration steps for ordinary use. Together image generation is optional and requires separate spending permission; a key's presence is not permission. Do not inspect credential stores or start imagegen automatically. Existing native image tools or supplied assets can serve a requested image task. Public font/photo downloads still need source and usage-right checks.
